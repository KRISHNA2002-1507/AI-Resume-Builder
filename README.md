# AI-Resume-Builder

## 📌 Description
This is a full-stack web application built using React.js and Node.js.


---## 🛠️ Tech Stack
- Frontend: React.js, HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB

---

## 📂 Project Structure
/client  → Frontend code  
/server  → Backend code  

---

### 2. Install dependencies

#### Client
cd client
npm install
npm start

#### Server
cd server
npm install
npm run dev

---

## 🔑 Environment Variables
Create a `.env` file in server folder and add:

MONGO_URI=your_mongodb_url  
PORT=5000  
JWT_SECRET=your_secret  

---

## ✨ Features
- User Authentication  
- API Integration  
- Responsive UI
